# Dashboard modernizada

A dashboard do MyRouter ERP foi modernizada preservando a estrutura e os módulos existentes.

## Alterações
- novo cabeçalho de boas-vindas;
- indicadores de clientes, O.S., contas a receber e bloqueios;
- gráfico de recebimentos dos últimos 6 meses;
- resumo operacional;
- faturas do mês com ações existentes;
- ações rápidas para Clientes, Assinaturas, O.S. e Planos;
- layout responsivo para telas menores;
- valores carregados diretamente do banco de dados existente;
- links dos módulos legados preservados.

## Arquivo principal
`app/dashboard/index.php`

A versão completa do ERP continua disponível no pacote ZIP de modernização publicado anteriormente.
