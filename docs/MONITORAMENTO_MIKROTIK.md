# Monitoramento MikroTik

A central `?app=Monitoramento` consulta o RouterOS sem alterar configuração.

## Dados
- conectividade e latência
- CPU e carga
- memória
- versão e modelo
- uptime
- PPP/PPPoE ativos
- interfaces e estado
- consulta instantânea de RX/TX por interface

A API usa a biblioteca RouterOS já existente no MyRouter e respeita a empresa da sessão.
